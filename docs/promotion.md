# Aera 产品介绍与功能演示方案

本文基于 Aera 1.3.0 整理，提供项目简介、功能演示结构与发布介绍文案。

## 一、产品定位

Aera 是一款轻量级 Android 大模型对话客户端。用户通过自备接口地址与 API Key 接入模型服务，在统一界面中完成多模型对话、文档分析、提示词复用、联网检索与代码阅读。

客户端界面围绕对话与阅读设计，安装包体积精简，支持在本地管理多套供应商配置、会话分支、历史检索与数据备份。

### 1. 安装包与系统兼容

最低支持 Android 7.0（API 24），采用原生 View 构建主界面，冷启动后直接进入当前对话输入状态。

### 2. 阅读排版与流式交互

主页聚焦对话内容与输入栏，支持 Markdown、LaTeX 公式、紧凑等宽语法着色代码卡片与 HTML / SVG 静态预览。流式生成期间上滑页面可固定当前阅读位置，长对话内支持按关键词精确查找并跨分页跳转。

### 3. 多供应商与模型配置

原生支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 与 Google Gemini 协议，支持配置多个供应商、独立设置单会话参数，并按模型能力切换思考强度档位。

### 4. 典型演示场景

#### 文档导入与视觉转写

从系统文件管理器选中 PDF 或 Office 文档分享至 Aera，附件自动进入当前对话草稿。可进一步展示为 PDF 与图片分别指定视觉识别模型，提取文本后交由主对话模型分析。

#### 提示词模板与图形预览

从输入栏打开提示词库，选择带 `{{变量名}}` 的模板填写参数并插入输入框，生成 SVG 代码后展示语法着色、横向滚动与四分之三屏图形静态预览，最后将当前对话分支导出为 `.md` 文件。

| 模块 | 功能说明 |
| --- | --- |
| 多协议与思考控制 | 支持四类原生协议、采样参数配置、思考强度调节与可读思考内容展示 |
| 草稿与提示词库 | 按对话自动保存文本、选区和附件草稿，支持变量化提示词模板检索与插入 |

| 多任务与后台连接 | 支持多会话并行生成、消息队列、前台服务后台生成及可选 Shizuku 省电豁免 |

## 五、发布简介参考

### 标题

Aera 1.3.0｜轻量级 Android 多协议大模型对话客户端

### 简介正文

Aera 是一款支持自定义 API Key 与服务地址的 Android 大模型对话客户端，原生兼容 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 与 Google Gemini 协议。

1.3.0 版本新增按对话保存输入草稿、支持 `{{变量名}}` 占位符的提示词库、当前会话内关键词查找，以及会话分支与单条消息的 Markdown 文件导出，并改进流式渲染帧合并、阅读位置保持与后台生成任务管理。

项目仓库与安装包下载分别见 [GitHub 仓库](https://github.com/Naiadxbzy/Aera) 与 [GitHub Releases](https://github.com/Naiadxbzy/Aera/releases)。

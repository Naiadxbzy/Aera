# Aera 项目介绍与宣传视频重点

> 轻装上阵，专注对话。
>
> 一款轻量、纯净、可自行配置模型服务的 Android AI 对话客户端。

本文基于 Aera 1.2.0 的实际功能整理，可作为宣传视频的项目介绍、配音底稿和剪辑参考。

## 一、项目是什么

Aera 把模型对话、文档处理、联网搜索和代码阅读，放进一个小体积的 Android 客户端中。用户自行配置模型提供商、接口地址与 API Key，在同一个界面里使用所需的模型服务。

它的重点是轻量与纯净：安装包小，首页围绕聊天展开，无广告干扰，无需注册 Aera 账号。模型怎么选、接口连到哪里、哪些功能需要开启，由用户自己决定。

日常聊天之外，Aera 也提供图片与文件附件、PDF 与图片转文字、会话管理、代码语法配色、SVG / HTML 静态预览和后台生成等能力，让小体积客户端也能承担实际工作。

**适合的人：** 已经有模型 API Key，希望在 Android 上获得简洁界面、自由配置服务，并经常阅读文档或处理代码的用户。

### 1. 轻量：把小体积直接展示出来

当前签名安装包为 **6,445,902 字节，约 6.15 MiB / 6.45 MB**，版本为 1.2.0。视频口播可简化为“约 6 MB”，文件详情画面则展示实际数值。

最低系统版本为 Android 7.0。小体积是可以直接证明的优势，适合成为视频开场的记忆点。

不要把 APK 体积换算成未经测量的内存、耗电或速度优势。视频中展示实际打开和操作过程即可。

### 2. 纯净：让界面自己说明问题

首页以对话和输入为中心，没有推荐信息流或社交广场。历史记录、模型与功能设置各有入口，技术详情按需查看。

浅色与深色主题、可调整的主题配色，以及紧凑的代码卡片，服务于长时间阅读和使用。可以通过一次主题切换、一次历史列表滑动来呈现，不需要密集转场。

“纯净”在视频里应当是一种能看见的体验：界面干净、操作直接、聊天内容清晰。

### 3. 自由：模型与服务由用户选择

Aera 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Google Gemini 原生协议，可按服务实际支持情况接入 GPT、Claude、Gemini、DeepSeek 等模型及兼容接口。

用户可以配置多个供应商和模型，自行填写接口地址与 API Key。新对话继承上次所选模型，思考强度按模型能力提供选择，可读的思考内容也能展开查看。

视频中重点展示“同一个客户端，可以选择自己的模型”，接口协议名称和参数配置留给说明文字。

### 4. 实用：选两个场景，把流程演示完整

**场景 A：收到一份文档，接着就能问。**

从系统文件管理器或其他应用分享文档到 Aera，附件进入输入区，用户确认后再发送。PDF 转文字与图片转文字可以分别配置识别模型，再将识别结果交给对话模型处理。

这个场景体现了日常工作的便利，也能展示“模型各司其职”的配置自由。

**场景 B：生成一段 SVG，边读代码边看效果。**

展示语法配色、横向拖动和完整展开，再打开 3/4 屏 SVG 预览。浅色主题采用浅灰代码背景，小号等宽字体让源码与正文区分清楚。

这一段画面直观，适合成为视频中最容易记住的功能演示。

## 七、介绍时需要说清的边界

Aera 是连接模型服务的客户端，使用前需要自行配置 API Key。聊天、搜索和文档识别会根据设置向相应服务发送必要内容；不能宣传为“全部离线运行”或“所有模型免费使用”。

文档、思考内容、搜索与工具的可用性取决于接口和模型。SVG / HTML 为静态预览；后台增强也不能保证实际断网或强制停止后继续生成。

视频最重要的记忆点应当始终是：**用一个小体积、干净、可自由配置的客户端，完成日常 AI 对话与工作。**

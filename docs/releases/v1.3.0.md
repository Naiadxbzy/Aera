# Aera v1.3.0 · 草稿保存、提示词库、会话内查找与 Markdown 导出

## 新增功能

- 按对话自动保存未发送文本、光标选区与待发附件，切换会话或重建界面后自动恢复，历史列表同步显示草稿标识，发送或入队成功后自动清理。
- 新增提示词库，支持在「设置 → 提示词库」与聊天输入栏新建、编辑、删除及搜索提示词模板，插入时可填写 `{{变量名}}` 占位符并写入当前光标或选区位置。
- 新增当前对话分支内关键词查找，提供实时命中计数、正文与思考内容高亮、跨分页上下跳转，以及区分大小写、全词匹配和思考内容匹配选项。
- 支持从聊天页菜单、历史列表菜单或单条消息操作中，通过系统文件选择器将当前对话分支或指定消息导出为 UTF-8 `.md` 文件，保留 Markdown 源文、角色、时间戳、模型名称、附件名称与来源链接。

## 交互与流式渲染优化

- 合并流式正文与思考内容的界面刷新调度，稳定流式传输期间未闭合代码块、LaTeX 公式与思考块的排版显示。
- 优化流式输出期间的阅读跟随逻辑，用户上滑浏览时保持当前分页与阅读位置，生成结束后就地更新消息视图，点击回到底部按钮即可恢复跟随。
- 优化软键盘收起与弹出时的 Insets 动画过渡，改进 Markdown 链接短按打开与长按文本选择的手势区分。

## 稳定性与底层修复

- 按服务实例跟踪活动生成任务，修复前台生成服务结束与新请求立即启动交错时的生命周期竞态，停止生成时同步取消待执行的附件预处理任务。
- 消息队列绑定所属对话分支，确认服务接管后再写入会话消息，配置缺失时保留队列并给出提示。
- 收敛会话数据持久化至 `SessionRepository`，在同一事务中写入最终回复并清理检查点，统一异步标题更新与会话删除时的检查点清理。
- 历史全文搜索改用独立会话快照与原始字符串偏移量计算高亮区间，修复多字节 Unicode 大小写折叠引起的摘录错位。
- 增强 SSE 流式解析器对非空行分隔、跨块 UTF-8 拆分与截断帧的兼容性，优化 OpenAI Responses 有序增量拼接性能。
- 限制内联附件、大响应与 ZIP 备份导入的内存占用，超限历史 PDF 自动切换至文件流路径，补充编辑弹窗预着色与 Shizuku 服务类的保留规则。

版本信息为 `1.3.0`（`versionCode 6`），沿用 `com.changyu.ochat` 应用 ID 与原发布签名，支持直接覆盖升级旧版本。

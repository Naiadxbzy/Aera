# Aera v1.4.1 · 对话内生成图片工具

现在可以在聊天输入栏直接调用图片生成工具，无需跳转页面即可在对话中生成、预览和保存图片。

## 新增功能

- 聊天输入栏新增「生成图片工具」按钮与状态胶囊，可随时开启或关闭对话内生图模式，并在胶囊或「设置 → 图片生成工具」中切换生图供应商、模型 ID 与画幅。
- 支持两种提示词方式，默认为 **AI 分析并编写提示词**：
  - **AI 分析并编写提示词（默认）**：当前对话模型结合上下文与附件分析用户请求，自动编写详细提示词后再调用生成图片工具，并保留思考过程与工具调用记录。
  - **自己写提示词（直接生图）**：将用户输入直接提交给生图模型，不经过对话模型改写。
- 生成的图片直接内嵌展示在对话回复中，支持点击全屏预览、查看/复制/填入输入框复用提示词、导出保存到本机，以及随重试、分支切换、排队发送与 Markdown 导出协同工作。

## 升级说明

此版本的 `versionCode` 为 `8`，沿用 `com.changyu.ochat` 应用 ID 与原发布签名，支持覆盖安装 1.4.0 及更早版本。

# Aera v1.1.1 · 分类型文档识别与原生工具扩展

- 移除 PDFBox 依赖，改用 Android 系统组件完成 PDF 页面渲染。
- 模型详情新增独立的「PDF 转文字」与「图片转文字」配置，支持分别为 PDF 与独立图片启用识别并指定视觉模型，识别结果按附件内容与模型缓存后提交给当前对话模型。旧版文档识别配置自动迁移至「PDF 转文字」。
- 针对 DeepSeek 官方接口，`deepseek-flash` 在未启用转文字时直接接收 PDF 页面图像，文本模型可通过「PDF 转文字」读取扫描版文档。
- 保留 PDF 原文件快照、流式编码传输与客户端翻页预览，系统分享导入附件后需手动点击发送才发起模型请求。
- 新建对话默认沿用上一活动对话所选模型，供应商协议选择页新增官方接口地址格式说明。
- 扩展 Anthropic 与 Gemini 的原生联网搜索、网页读取和代码执行支持，以及 OpenAI Responses 代码执行与 Chat Completions 搜索模型支持。

版本信息为 `1.1.1`（`versionCode 3`）。

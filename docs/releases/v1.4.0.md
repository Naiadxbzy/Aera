# Aera v1.4.0 · 图片与视频生成

在聊天页打开「对话操作 → 图片与视频」，选择供应商及模型，输入提示词即可生成图片或视频。

## 新增功能

- 图片生成支持 OpenAI Images、兼容接口和 Gemini 图片模型，可按模型选择画幅。
- 视频生成支持 Gemini Omni Flash，以及实现 `/videos` 创建、查询和下载接口的兼容供应商。可按模型选择画幅和时长。
- 生成任务可在后台运行。生成记录支持按会话查看，图片可预览，视频可播放，结果可保存到本机。
- 视频中断后，已获得远程任务编号的记录可继续查询并下载原任务结果。未完成的记录支持手动重新生成。

## 升级说明

此版本的 `versionCode` 为 `7`，沿用 `com.changyu.ochat` 应用 ID 与原发布签名，支持覆盖安装 1.3.0。

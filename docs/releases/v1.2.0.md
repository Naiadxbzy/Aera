# Aera v1.2.0 · 后台连接管理与代码预览优化

- 项目与应用显示名称统一为 Aera，沿用 `com.changyu.ochat` 应用 ID 与原发布签名，支持直接覆盖升级并保留本地数据。
- 新增「设置 → 后台连接」页面，集成电池优化、后台受限与生成通知的状态检测及系统设置入口。
- 默认开启基础后台增强，生成期间维护带超时的唤醒锁并将单次流式读取静默超时延长至 10 分钟，支持前置步骤断网等待与自动恢复，请求中断时保留已接收的正文与思考内容并暂停消息队列。
- 新增可选 Shizuku 省电豁免（需 Shizuku v13 及以上版本），支持为本应用查询、添加、校验与撤销系统 Doze 白名单。
- 识别无代码围栏的独立 SVG 与 HTML 源码并统一纳入代码卡片渲染与静态预览。
- 代码卡片与源码视图适配浅色、深色及自定义主题配色，统一等宽字体排版、语法着色、双向滚动、完整展开与复制操作。
- 修复签名安装包归档任务 `archiveReleaseApk` 与 Gradle 配置缓存的兼容性问题。

版本信息为 `1.2.0`（`versionCode 4`）。

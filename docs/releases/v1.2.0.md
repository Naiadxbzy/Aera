# Aera v1.2.0 · 后台连接与代码显示优化

保持轻量与纯净，优化后台生成、代码阅读和 SVG 预览体验。

- 项目与应用品牌统一为 Aera，沿用原应用 ID 和发布签名，支持覆盖升级并保留本地数据。

- 新增「设置 → 后台连接」，提供电池优化、后台限制和生成通知的状态检查与设置入口。
- 普通增强默认开启：生成请求的静默等待延长至 10 分钟，并在生成期间维护唤醒锁；没有任务时不额外保活。
- 监听断网与网络恢复，尚未发送的步骤可等待恢复后继续；已提交的请求不会因切网自动重发，减少重复回答与计费风险。
- 保留已生成的文字和思考内容；生成失败后暂停推进消息队列，方便检查后再继续。
- 可选 Shizuku 省电豁免，支持授权、实际状态验证与撤销，仅调整 Aera 自身设置。
- 完善退出设置页、取消请求和网络切换时的处理。
- 修复发布安装包归档任务与 Gradle 配置缓存的兼容问题。
- 修复直接输出 SVG 时只显示标题和描述的问题，历史消息、流式回复及 XML 标记的 SVG 统一使用代码卡片并支持预览。
- 代码卡片与源码页跟随浅深主题，采用紧凑的等宽字体、语法配色、细分隔线和统一的复制 / 预览操作，保留双向滚动与完整展开。

Shizuku 增强需要先安装并启动 Shizuku v13 或更新版本，再在 Aera 中授权开启。增强不能保证实际断网、强制停止或系统运行时限下永不中断。

版本：1.2.0；versionCode：4。继续使用原发布签名，可覆盖安装旧版正式包。
